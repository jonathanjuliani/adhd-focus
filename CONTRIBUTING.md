# Contributing

How to change the one skill in this plugin.
Open this before editing `SKILL.md`. The authoring rules are in [`.agents/conventions.md`](.agents/conventions.md).
Back to [adhd-focus](README.md).

The skill lives at `plugins/adhd-focus/skills/adhd-focus/SKILL.md`. The folder name is the skill name.

## Before you open a pull request

```bash
python3 scripts/validate.py
python3 scripts/version.py --check
```

Add a line under `## [Unreleased]` in [CHANGELOG.md](CHANGELOG.md).
